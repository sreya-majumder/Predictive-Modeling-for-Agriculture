A machine learning classification project that predicts optimal crops based on soil characteristics such as nitrogen, phosphorus, potassium, and pH levels.

# Crop Prediction Using Machine Learning 🌱

## Overview

This project uses machine learning to predict the most suitable crop based on soil characteristics. The model analyzes soil measurements such as nitrogen (N), phosphorus (P), potassium (K), and pH levels to classify the optimal crop for a given field.

## Dataset

The dataset contains soil measurements and crop labels.

Features:
- N: Nitrogen content
- P: Phosphorus content
- K: Potassium content
- pH: Soil pH value

Target:
- crop: Recommended crop

## Approach

- Explored and analyzed soil data
- Built a multi-class classification model using Logistic Regression
- Evaluated model performance
- Identified the most predictive soil feature

## Technologies Used

- Python
- Pandas
- Scikit-learn
